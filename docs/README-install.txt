RamPanel 1.2.0
Тайминги, скорость памяти, FCLK и режим UCLK (1:1 / 1:2 / Auto) для компьютеров на AMD Ryzen.

Уровни поддержки (RamPanel определяет сам при запуске, видно на вкладке «Настройки»)
  Проверенное устройство   полная поддержка, после записи настройки BIOS сверяются байт в байт.
                           Сейчас в списке одно: Lenovo Legion R7000P 16ADR10 (83LT) · BIOS RLCN31WW · Ryzen 9 8945HX.
  Экспериментальный режим  любой AMD с интерфейсом разгона AMD в BIOS и памятью DDR4/DDR5.
                           Команды и допустимые значения берутся у самого BIOS. Запись выключена, пока её не
                           включить галочкой на вкладке «Настройки» (на свой риск). Если формат настроек BIOS
                           незнакомый, записанное проверяется только после перезагрузки.
  Только просмотр          нет интерфейса разгона AMD (многие производители его убирают), распаянная LPDDR
                           или не AMD.

Как работает
  Значения уходят в BIOS через штатный интерфейс разгона AMD (WMI AMD_ACPI, тот же, что у Ryzen Master)
  и включаются после перезагрузки. После каждой записи RamPanel запоминает, что просили, и после перезагрузки
  сверяет с тем, что реально работает, — если BIOS что-то отклонил или откатил, будет предупреждение.

Осторожно
  Слишком жёсткие значения могут не дать компьютеру загрузиться. Встроенный откат AMD (APCB recovery)
  срабатывает только если память не проходит тренировку; если тренировка прошла, а система виснет позже,
  нужен ручной сброс CMOS — на многих ноутбуках только с разборкой. Меняйте по одному значению маленькими
  шагами и сохраняйте рабочий профиль.

Файлы
  RamPanel.ps1         - окно
  Get-LiveTimings.ps1  - чтение работающих таймингов
  ZenStates-Core.dll   - библиотека чтения таймингов (irusanov, ZenStates-Core 1.79, из ZenTimings)
  inpoutx64.dll        - доступ к портам ввода-вывода (Highresolution Enterprises, freeware)
  rampanel.log         - журнал записей в BIOS, backup\ - копии настроек BIOS перед каждой записью
